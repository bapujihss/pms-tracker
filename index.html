How to enable live multi-user read/write in Firebase Console (takes 30 seconds):

  1. Open Firebase Console → bapujihss → Realtime Database → Rules.
  2. Click Copy Firebase Rules below, paste into the Rules editor, and click Publish.
  3. Come back here and click Test & Push Data Now.
database.rules.json (Scoped & Validated for schools/school_01) 
{
  "rules": {
    ".read": false,
    ".write": false,
    "schools": {
      "$schoolId": {
        ".read": true,
        ".write": true,
        "students": {
          "$studentId": {
            ".validate": "newData.hasChildren(['id', 'name', 'rollNo']) && newData.child('name').isString() && newData.child('rollNo').isString()"
          }
        },
        "teachers": {
          "$teacherId": {
            ".validate": "newData.hasChildren(['id', 'name', 'username', 'role']) && newData.child('username').isString()"
          }
        },
        "meta": {
          ".validate": "newData.hasChildren(['updatedAt'])"
        },
        "presence": {
          "$sessionId": {
            ".validate": "newData.hasChildren(['online', 'updatedAt'])"
          }
        }
      }
    }
  }
}

Tip: If you enable Anonymous Auth in Firebase Console → Authentication, you can also replace true with "auth != null".
